## 📌 Featured Project

### 🚀 PromoGen

A multi-threaded account registration tool built for speed and automation.

**Features**

- Multi-threaded account registration
- Email verification support (OTP fetching implementation left to the user)
- Rotating proxy support with authentication
- Automatic browser window organization (1–8 threads)
- Email queue system for sequential processing
- Automatically saves verified accounts in `email:password` format

🔗 https://github.com/LegendOnTop/promogen
